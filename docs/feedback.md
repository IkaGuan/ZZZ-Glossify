# Bug reports and feature requests · 问题反馈与建议

[English README](../README.md) · [中文说明](../README.zh-CN.md) · [GitHub Issues](https://github.com/IkaGuan/ZZZ-OilSkinBoo/issues)

## English

Found a bug or have an idea for the mod? Open a GitHub issue. Check for an existing report first, and keep each issue focused on one bug or feature request. English and Chinese are both welcome. Use a descriptive title, such as “Glossy hair on [agent] with [skin mod]”.

### Reporting a bug

Describe what you did, what you expected, and what actually happened. Include enough detail for someone else to reproduce it. For visual problems, screenshots or a short video help; for errors, copy the full message. If the issue involves a character mod, include its name, version, and public download link when available. Do not redistribute someone else's mod without permission.

Check whether the issue also happens on the original character model. If practical, check with only OilSkin 2 and one OilSkinBoo variant enabled. Specify whether you're using Standard or Glossify and which UI language. Report the result rather than assuming which mod caused it. Include your Face/Body switches, style, strength, and whether the preset says Saved or Default. **Seth is currently unsupported.**

### Requesting a feature

Describe what you'd like to do, what's getting in the way, and how your proposed change would help. An example or mock-up is useful, but you don't need to provide an implementation. All suggestions are welcome, though not every request will make it into the mod.

```text
Title: Feature request — [short description]

What problem would this solve?
When do you encounter it?
What would you like to happen instead?
Example or mock-up (optional):
Current workaround (if any):
```

## 简体中文

### 反馈 Bug

说明你做了什么、预期发生什么、实际发生什么，并提供别人可以照着操作的复现步骤。画面问题请附截图或简短视频；报错请提供完整原文。涉及角色 Mod 时，请注明名称、版本及可用的公开下载链接，不要未经许可重新分发他人的 Mod。

请检查原版角色模型是否也有同样问题。如果方便，再尝试只启用 OilSkin 2 和一个版本的油光布，并写明结果，不必预先判断是哪一个 Mod 导致。请注明使用标准版还是全油化版、面板语言，以及面部／身体开关、样式、强度和预设显示“已保存”还是“默认”。**当前版本暂不支持赛斯。**
